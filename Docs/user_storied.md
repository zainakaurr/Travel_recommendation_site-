# User Stories

| ID | Epic | User Story | Priority | Acceptance Criteria |
|------|-------|--------------|-----------|----------------------|
| US-1 | Route Planning | As a traveler, I want to enter a source and destination so that I can generate a travel route. | High | User can input valid locations and submit route request successfully. |
| US-2 | Route Planning | As a traveler, I want to view my route on an interactive map so that I can visualize my trip | High | Route polyline and destination markers appear clearly on the map. |
| US-3 | Attraction Discovery | As a traveler, I want to see attractions along my route so that I can discover places to visit. | High | Attractions appear as markers along the generated route |
| US-4 | Attraction Discovery | As a traveler, I want information cards of each attraction so that I can learn more about each location. | Medium | Attraction cards display name, category and brief description (place, why visit, cautions, etc). |
| US-5 | Attraction Discovery | As a traveler, I want to be able to filter attractions based on interests so that I am only shown what I am interested in. | Medium | Traveller only sees sites that line up with their interests such as, nature, birds, food etc. |
| US-6 | LLM Recommendations | As a traveler, I want AI-generated sightseeing and attraction recommendations so that I can receive personalized suggestions | High | LLM successfully generates recomendations based on user interest and route. |
| US-7 | LLM Recommendations | As a traveler, I want AI to personalize my route based on my interests so that my trip feels more fulfilling | High | LLM successfully suggests routes that help user make most out of their trip. |
| US-8 | Cybersecurity & Privacy | As a traveler, I want safety warnings so that I can avoid digital risks while traveling | Medium | App displays travel-related cyber safety ups and warnings for all destinations. | 
| US-9 | Cybersecuirty & Privacy | As a privacy cautious traveler, I want a private use mode so that my location history is not stored unless specified to be | High | No user trip history is stored while user is in private mode. |
| US-10 | Login | As a travel site user, I want to be able to create an account to keep track of my use sessions so that I can refer back to them | High | User is able to login. |
| US-11 | Saved Trips | As a  traveler, I want to be able to save trips so that I can view them later | High | User is able to favourite trips and routes. |
| US-12 | Offline View | As a traveler, I want to be able to download PDFs of trips so that I can view them offline | High | User is able to download trips before going offline. | 
| US-13 | Accessibility & UI | As a traveler, I want the site to be able to work on mobile devices so that I can use it while travelling | High | UI is responsive across desktop and mobile screen sizes. |
| US-14 | Accessibility & UI | As a traveler with low vision, I want the site to have a high contrast mode so that I can read easily without straining my eyes | High | UI has accessibility settings which include High Contrast Mode. |
| US-15 | Accessibility & UI | As a traveler with limited hand mobility, I want the site navigation to flow with only keyboard tab kesy so that I can use it without needing a mouse. | High | User is able to navigate site with just keyboard. |
